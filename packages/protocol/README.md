# @violentmonkey/mcp-protocol

Shared wire protocol for [`@violentmonkey/mcp`](https://www.npmjs.com/package/@violentmonkey/mcp).

- `@violentmonkey/mcp-protocol`: constants and inferred types, no runtime dependencies.
- `@violentmonkey/mcp-protocol/schemas`: zod tool and message schemas, used by the server.

See the [protocol docs](https://github.com/violentmonkey/mcp/blob/main/docs/protocol.md).
